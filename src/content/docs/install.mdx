---
title: Installation
---

Clone the Git Audio project and run the installation script:

```shell
git clone https://github.com/dnhn/git-audio && cd git-audio && \
make install
```

This sets up the configuration directory in your home folder and installs the `git-audio` CLI to `/usr/local/bin`.
You can now run `git-audio` from anywhere in your terminal.

## Uninstallation

```shell
make uninstall
```

This removes the `git-audio` CLI from your system. Configuration files and repository hooks remain intact.
