---
title: Installation
---

Clone Git Audio project and run the installation script:

```shell
git clone https://github.com/dnhn/git-audio && cd git-audio && \
make install
```

This will set up the configuration directory in your home folder and install the `git-audio` CLI to `/usr/local/bin`.
You can now run `git-audio` from anywhere in your terminal.

## Uninstallation

```shell
make uninstall
```

This will remove the `git-audio` CLI from your system.
The configuration and hooks you have installed in your repositories will remain intact.
