Clone the Git Audio project and run the installation script:

```shell
git clone https://github.com/dnhn/git-audio && cd git-audio && \
make install
```

This sets up the configuration directory in your home folder and installs the `git-audio` CLI to `/usr/local/bin`,
which requires `sudo` privileges. After installation, you can run `git-audio` from anywhere in your terminal.

## Configuration

Configuration is stored in `$HOME/.git-audio/`:

<FileTree>
- audio.wav
- cli.sh
- config.sh
- templates
  - hooks
    - post-commit
</FileTree>

## Uninstallation

This only removes the `git-audio` CLI. Configuration files and repository hooks remain in place.

```shell
make uninstall
```
