Configuration is stored in `$HOME/.git-audio/`:

<FileTree>
- audio.wav
- config.sh
- templates
  - hooks
    - post-commit
</FileTree>

## Custom audio

By default, `audio.wav` is played.
To change the audio, update the absolute path in `config.sh`:

<Code
  code={`export GIT_AUDIO="/path/to/your/audio"`}
  lang="shellscript"
  title="~/.git-audio/config.sh"
/>
